# 小さな物語 — маленькие истории

Статический сайт для чтения по урокам Genki I и II, третье издание. Интерфейс на JavaScript, сборщик на Node.js 22 или новее. Без PHP, базы данных и сторонних npm-зависимостей. Для размещения подходит GitHub Pages.

## Открыть сайт

Из папки проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:5173. После редактирования файлов обновите страницу. Установка пакетов не нужна.

Для готовой сборки: `npm run build`. Результат — папка `dist`, её можно разместить на любом статическом хостинге. Проверить готовую сборку локально: `npm run preview`. Открытие HTML двойным щелчком не поддерживается: загрузке данных нужен HTTP-сервер.

OSPanel также можно использовать: сначала выполните `npm run build`, затем перезапустите панель. `.osp/project.ini` направляет домен `jpstories.local` в папку `dist`; PHP сайту не нужен.

## Публикация на GitHub Pages

1. Загрузите проект в репозиторий GitHub, в ветку `main` (включая папку `.github`).
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Во вкладке **Actions** запустите **Deploy GitHub Pages → Run workflow**. Последующие изменения в `main` публикуются автоматически.
4. После успешного завершения адрес появится в **Settings → Pages** и в результате задания публикации.

Если основная ветка называется иначе, замените `main` в `.github/workflows/pages.yml`. Настраивать имя репозитория в коде не нужно: используются относительные пути, поэтому поддерживается и адрес вида `https://имя.github.io/репозиторий/`.

## Добавить историю

Создайте в папке `stories` любой файл с расширением `.txt`, сохранённый в UTF-8. Например, `04-my-room.txt`:

```text
title: 私の部屋
subtitle: Моя комната
lesson: 4
---
[私|わたし|я][の||частица принадлежности][部屋|へや|комната][です||вежливая связка: «это»]。
```

В режиме `npm run dev` после сохранения обновите страницу. Для статического хостинга пересоберите сайт; на GitHub достаточно сохранить изменение в `main` и дождаться публикации. Файлы подхватываются автоматически, список вручную обновлять не нужно. Название файла служит идентификатором для отметки о прочтении. Истории сортируются по уроку, затем по имени файла. Уроки 1–12 относятся к Genki I, 13–23 — к Genki II. Некорректные файлы останавливают сборку с сообщением об ошибке, чтобы история не исчезла незаметно.

Первая часть — три поля: японский заголовок `title`, русский подзаголовок `subtitle` (необязательно), номер урока `lesson`. Отдельная строка `---` отделяет текст. Пустая строка начинает новый абзац.

Необязательные поля: `note` — пояснение об уровне и дополнительной лексике; `series` — название общей истории; `chapter` — положительный целый номер главы внутри серии. Например, `series: Чей фотоаппарат?` и `chapter: 1`. Главы серии собираются в одну большую историю (см. ниже). Абзац `Вопросы к тексту` отображается как отдельный заголовок; слова в вопросах размечаются тем же способом.

Каждое слово записывается как `[слово|чтение|перевод]`. Если чтение не нужно: `[これ||это]`. Частицы тоже размечаются: `[は|わ|тема предложения]`. Знаки препинания оставляйте за скобками. Не используйте `|` или `]` внутри полей. Весь текст вне разметки отображается буквально и не имеет перевода. HTML не исполняется.

Переводы задаются непосредственно в контексте истории; внешних переводчиков и API нет. В примерах глагольная форма может быть одной кликабельной единицей. Можно размечать устойчивые сочетания целиком.

## Большие истории из нескольких глав

Главы с одинаковым `series` сайт показывает как одну историю. Слева под уроками есть карточка с прогрессом и кнопкой «Начать с главы 1» или «Продолжить: глава N». Ещё есть оглавление по адресу `#series=camera`. В читалке над текстом выводится полоса с номерами глав. В списках уроков главы помечены «Большая история». Если у истории в одном уроке несколько глав, они показываются одной карточкой, которая ведёт к оглавлению.

«Продолжить» ведёт к последней открытой главе, если она ещё не отмечена прочитанной. Иначе — к следующей непрочитанной. Если открыть урок кнопкой, это не считается выбором главы. Отметки хранятся в браузере, как и отметки «Прочитано».

Описание серии лежит в `series/<адрес>.txt`, имя файла становится адресом страницы (латиница, цифры, дефис):

```
series: Чей фотоаппарат?
title: だれの　カメラ？
genre: Детектив
mark: 探
---
Короткое описание без спойлеров. Пустая строка начинает новый абзац.
```

`series` должен в точности совпадать с полем в главах. Поля `title` (японское название), `genre` и `mark` (один знак для печати на карточке) необязательны. Без файла описания серия всё равно работает. Тогда адрес берётся из имени первой главы: `01-camera-01` → `camera`. Сборка остановится, если в серии повторяется номер главы или если описание не совпадает ни с одной главой.

## Справочник: грамматика, словарь, кандзи, счёт

В шапке сайта рядом с «Историями» есть разделы «Грамматика», «Словарь», «Кандзи» и «Счёт». Под заголовком урока в историях — ссылки «Грамматика урока» и «Слова урока». Если слово из истории есть в словаре, во всплывающем переводе появляется ссылка «Найти в словаре».

Данные лежат в папке `reference` и редактируются как обычные текстовые файлы в UTF-8:

- `grammar/01.txt` … `grammar/12.txt` — правила урока. Сверху те же поля, что у историй (`lesson`, `title`, `subtitle`) и строка `---`. Каждое правило начинается со строки `## шаблон`, дальше строки пояснения и примеры вида `> 日本語の例 | перевод`.
- `vocab.tsv` — словарь, столбцы через Tab: урок, тип, кандзи, чтение, перевод, тема. Типы: `n` — существительное, `u` — う-глагол, `ru` — る-глагол, `irr` — неправильный глагол, `i` — い-прилагательное, `na` — な-прилагательное, `x` — прочее. Для слов без кандзи столбец кандзи пустой.
- `themes.txt` — список тем словаря в нужном порядке; тема в `vocab.tsv` должна совпадать с одной из них дословно.
- `kanji.tsv` — урок, знак, онъёми, кунъёми, значение.
- `counters.json` — таблицы счётных суффиксов: для каждого суффикса 11 чтений (1–10 и 何). Чтения со сдвигом звука сайт выделяет сам.

Сборка проверяет эти файлы и останавливается с понятной ошибкой: неизвестный тип или тема, неверное число столбцов, пример без перевода. Ссылки на разделы тоже можно сохранять: `#view=grammar&lesson=3`, `#view=vocab&theme=Дом и быт`, `#view=vocab&q=家`, `#view=kanji&lesson=5`.

Слова собраны по открытым спискам лексики Genki и сверены вручную. Свободного списка именно 3-го издания нет, поэтому отдельные слова в книге могут стоять в другом уроке.

## Сложность

В комплекте 35 текстов: пять первоначальных примеров, 18 историй из предоставленного архива (включая детектив из 12 глав) мистика «Семь чудес общежития» из 7 глав и уютный детектив «Ночной поезд» из 5 глав — обе уровня 12-го урока. Это не тексты учебника. Подробности импорта, назначенные уровни и исключения описаны в [IMPORT-NOTES.md](IMPORT-NOTES.md).

Номер урока — редакционная отметка, а не автоматическая проверка. В импортированных текстах сохранены номера источника, а дополнительные слова и замеченные опережающие конструкции отмечены в разделе «Об уровне текста». Двум текстам без номера назначены уроки 5 и 12 по грамматике. Часть лексики культурная и объясняется отдельно. Для строгого ограничения всей лексики и грамматики выбранным уроком потребуется дополнительная адаптация оригиналов. Написание кандзи снабжено чтением по нажатию; ограничения на кандзи отдельно не проверяются.

Отметки о прочитанном хранятся в текущем браузере. Шрифты загружаются из Google Fonts, при отсутствии интернета используются системные. Всё остальное работает локально.

При выборе истории ссылка меняется на `#story=имя-файла`, например `#story=01-camera-01`. Её можно сохранить или отправить: при открытии сразу выбираются нужные книга, урок и история. Обновление страницы и кнопки браузера «Назад»/«Вперёд» сохраняют выбранный текст. При посещении сайта без указанной истории восстанавливается последний выбранный текст из памяти текущего браузера. Для пустых уроков используется `#lesson=номер`.
